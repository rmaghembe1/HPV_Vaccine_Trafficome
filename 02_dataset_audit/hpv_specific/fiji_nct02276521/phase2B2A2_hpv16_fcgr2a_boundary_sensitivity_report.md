# Phase 2B2A2 HPV16–FcγR2A boundary sensitivity

## Decision

**READY_FOR_PHASE2B2D_INTEGRATION_AND_BIOLOGICAL_SYNTHESIS**

The repaired mixed model converged at an effectively zero random-intercept variance, indicating a boundary solution. The same fixed-effect design was therefore refitted using participant-clustered robust covariance.

- Contrasts compared: 11
- Direction agreement: 11/11
- Nominal significance agreement: 8/11
- Maximum absolute estimate difference: 1.8318679906315083e-14

Because the random-intercept variance approached zero, the cluster-robust fixed-effects analysis provides the appropriate sensitivity confirmation. The paired Phase 2B1 analysis remains the primary two-visit inference.
