# Phase 2C1 Fiji multivariate readiness

## Decision

**READY_FOR_PHASE2C2_BREADTH_AND_PHASE2C3_FUNCTIONAL_COUPLING**

- Participants: 80
- Raw participant matrix: 80 × 92
- BPV-calibrated participant matrix: 80 × 77
- BPV-calibrated long records: 6160
- Feature-manifest rows: 169
- Readiness-audit strata: 12

The raw matrix contains participant-level paired log2 changes for all 92 antigen-feature combinations. The BPV-calibrated matrix contains the 77 HPV variables that share an assay feature with the heterologous BPV control. Primary and recall groups should be analyzed separately where biological context is central. Dose-specific recall analyses have limited sample sizes and should emphasize descriptive structure, stability and effect concordance rather than high-dimensional prediction.
