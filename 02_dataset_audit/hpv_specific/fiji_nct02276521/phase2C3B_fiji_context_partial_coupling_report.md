# Phase 2C3B Fiji context and partial coupling

## Decision

**READY_FOR_PHASE2C3C_FUNCTIONAL_COUPLING_SYNTHESIS**

- Primary-versus-recall correlation comparisons: 50
- Recall partial correlations adjusted for categorical previous-dose group: 50
- Recall-dose correlation-heterogeneity tests: 50

Primary-versus-recall differences are evaluated with an approximate Fisher-z comparison of independent Spearman correlations. Recall partial associations are calculated by rank-transforming each variable and residualizing both ranks on categorical previous-dose-group indicators before correlation. Dose-group heterogeneity is evaluated across the one-, two- and three-dose recall strata using inverse-variance weighted Fisher-z heterogeneity statistics.

These analyses distinguish coupling associated with the primary-versus-memory immunological state from coupling that could be explained by previous-dose-group composition. Dose-group comparisons remain between randomized schedule groups and are not within-person measures of waning.
