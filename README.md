# HPV Vaccine Trafficome Project

## Project identity
A mechanistic systems-immunology study of HPV vaccine-response heterogeneity, centered on intracellular antigen handling, endolysosomal routing, HLA/MHC biogenesis, APC activation, B-cell/Tfh coupling, Fc-mediated immune communication, and metabolic-inflammatory regulation.

## Design principle
The project is HPV-anchored and comparator-supported. HPV-specific datasets define the biological phenotype; public systems-vaccinology transcriptomic and multimodal datasets are used to reconstruct conserved cellular mechanisms when equivalent HPV molecular data are unavailable.

## Primary biological axes
- Age and developmental immune state
- Vaccine dose, interval, formulation, and adjuvant
- Time after vaccination
- Baseline immune and inflammatory state
- Sex and health-state modifiers where metadata support them
- BMI/adiposity only where participant-level measurements are available

## Repository rule
Raw controlled-access data and identifiable participant information must never be committed. Large public raw files remain in `03_data_raw/` and are excluded from Git.
